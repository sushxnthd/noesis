This is classical structural-causal mediation/positivity nonidentifiability, **not a new learned-RNN theorem, prospective replication, or publication-grade novelty**. **Exact construction:** For either DFA task, given the complete initial state, the entire intermediate state path P_q(w) determines each input bit (Task A: residue increments mod 3; Task B: the next state's previous-bit coordinate). Define an auxiliary rational contracting word map F_w(z)=z/2+sigma(w)/8, with sigma(u)=+1, sigma(v)=-1, otherwise 0, and three logits with oracle-class logit 2+z/2 and others zero. The auxiliary region [-1,1] is invariant, contraction factor 1/2, oracle margin >=3/2. Thus all input strings classify correctly.

Two structural decompositions yield identical q,z, logits and all input-word responses: A updates z using sigma(decode(P_q(w))); B updates z using sigma(w). They are identical on every realizable path because decode(P_q(w))=w. However, under the **hypothetical off-support** do(P=P_q(v)) while holding w=u, starting z=0, the real oracle-logit gap effect is -1/8 in A and 0 in B. No word-only estimator can distinguish them; a two-point minimax absolute-error lower bound is **1/16**, regardless of sample size. This does **not** assert that an independent DFA-path intervention is physically realizable in an RNN. Terminal-state-only mediation cannot reproduce both distinct u/v maps.
