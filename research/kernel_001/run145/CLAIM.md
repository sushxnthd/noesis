# Smallest supported claim — Run 145
An archived, ordinarily gradient-trained three-state ReLU counting network has a **provably Schur-stable raw recurrent matrix** but **provably unbounded output error** on repeated increments because a ReLU-invariant two-coordinate subnetwork expands. A standalone raw-matrix spectral-radius check is therefore not a sufficient test of learned algorithmicity or long-horizon stability. Exact rational proof and independent checker agree; first repeated-increment error >0.1 occurs at n=141. This is a learned-model counterexample to a diagnostic shortcut, not a new model-agnostic algorithm-acquisition certificate.
