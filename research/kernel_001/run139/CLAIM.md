# Smallest supported claim

Across eight previously gradient-trained ReLU RNN checkpoints with an exact plus-only unit recurrent ray, all eight have nonunit exact output gain. Each fails strict 0.1-accurate plus-only counting at a finite, exactly predicted length despite passing length-256 evaluation. This is a restricted, elementary negative result, not a model-agnostic certificate, not a new gradient-training intervention, and not a publication-level novelty claim.
