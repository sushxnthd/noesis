# NOESIS Kernel 001 / Run 294 — frozen protocol
Frozen before evaluating untouched models. Pilot seeds 21450..21455 were inspected locally and excluded, as were previously examined acquisition seeds 21494,21501,21549,21585,21674. The untouched set contains 245 of the 256 Run291 gradient-trained width-three epoch-20 networks.

1. Question: Can a function-preserving autonomous hidden clock change the Run293 gauge-normalized, proportional-quotient diagnostic? Can backward output-observability pruning remove this vulnerability?
2. Frontier: Observability/minimal realizations, neural-network equivalence, abstract interpretation, and graph pruning are prior art. Run142 already warned against unbounded irrelevant auxiliary states.
3. Single primary criterion: At least 150 of 245 untouched models change gauge-fixed LP score by >1e-6 after adding a divergent, output-silent clock, while exact-real outputs are preserved for all finite words.
4. Strongest alternative: The LP score measures global boundedness of all hidden coordinates rather than task-relevant algorithm acquisition.
5. Cheapest falsification: For each trained network, append an independent fourth neuron initialized at zero, with zero readout and zero feedback into the original three neurons. Compare stable h'=ReLU(h/2+1) and divergent h'=ReLU(2h+1). Verify structural equivalence in exact rationals; test mutations introducing readout or feedback.
6. Publishable threshold: Independent checker, priority audit, strong spoof baselines, prospective transfer to unseen task/architecture, and actual learning transition. This run alone is not a new acquisition law.
7. Learning relevance threshold: >=150 trained networks show a score change; backward output-ancestor pruning restores original score on all 245 networks.
8. Kill: <150 changed, any unsound pruning or failed equivalence proof. Three substantive failures require kernel reformulation.
